A newspaper-front-page poster that sums up Tuesday 17 November 2026 in one image: Ukraine strikes the Crimean Bridge again, Trump, Xi and Putin set a Shenzhen summit, Iran drones target a U.S. radar in Bahrain, tankers hit mines near Hormuz, Japan scrambles jets after an airspace breach, and five European states plan a Rwanda returns hub. Pure Python stdlib — the program draws the whole page (own PNG encoder, own 5x7 bitmap font, vector motifs) and writes entry.png. No network, fully deterministic: two runs write identical bytes.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
